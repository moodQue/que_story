Privacy Policy

Last updated September 2026

This policy covers moodQue's personal home-automation software ("moodQue Home"), a project run by a single household for its own use. It is not a commercial product, is not offered to the public, and is not used by anyone outside the household that runs it.

What this connects to

moodQue Home integrates with Google's Smart Device Management (SDM) API to read and control smart-home devices (for example, a Nest thermostat) that belong to the household running it. It may connect to other Google APIs for the same, single-household purpose.

What data is accessed

  • Device state needed for automation: e.g. current and target temperature, heating/cooling mode.
  • No data is collected about anyone other than the household running the software.
  • No continuous location history, no voice recordings or transcripts, and no financial or medical information are collected.

Where data goes

Data stays on infrastructure owned and operated by the household running moodQue Home. It is never sold, shared with advertisers, or forwarded to any third party. It is used only to decide what the household's own devices should do (for example, warming the house before someone arrives).

Retention and revocation

Data is retained only as long as needed to run the automation and is deleted when no longer needed. Access can be revoked at any time from your Google Account permissions page, which immediately stops moodQue Home from reading or controlling any device.

Contact

Questions about this policy can be raised via an issue on the moodQue GitHub organization.
